# CE Easy Trainer 集成指南

## 概述

本指南说明如何将 CE Easy Trainer 核心组件集成到 Cheat Engine 主程序中。

## 文件清单

### 核心单元
- `SmartPersistenceUnit.pas` - 智能持久化引擎（地址自动重定位）
- `EasyTrainerMainUnit.pas` - 简化主流程控制器
- `CTEasyCompatibilityUnit.pas` - CT 表扩展兼容层
- `AutoReattachUnit.pas` - 进程自动重连服务

### 适配器
- `CEBackendAdapter.pas` - CE 后端适配器（连接 CE 核心功能）

### 示例
- `EasyTrainerIntegration.pas` - 集成示例代码

### 测试
- `test_ce_easy_units.pas` - 单元测试（不依赖 CE）
- `test_SyntaxCheck.pas` - 语法检查测试

## 集成步骤

### 步骤 1：添加单元到工程

打开 CE 工程文件 (`Cheat Engine.lpi` 或 `.dpr`)，在 `uses` 部分添加：

```pascal
uses
  // ... 现有单元 ...
  SmartPersistenceUnit,
  EasyTrainerMainUnit,
  CTEasyCompatibilityUnit,
  AutoReattachUnit,
  CEBackendAdapter;
```

### 步骤 2：在 MainUnit 中初始化

在 `MainUnit.pas` 的 `TMainForm` 类中添加字段：

```pascal
type
  TMainForm = class(TForm)
    // ... 现有字段 ...
  private
    FEasyTrainerController: TEasyTrainerController;
    FAutoReattachService: TAutoReattachService;
    FCEBackendAdapter: ICEBackendAdapter;
    FCEProcessProbe: IProcessProbe;
    // ... 现有方法 ...
  end;
```

在 `FormCreate` 中初始化：

```pascal
procedure TMainForm.FormCreate(Sender: TObject);
begin
  // ... 现有初始化代码 ...

  // 初始化 Easy Trainer
  FCEBackendAdapter := TCEBackendAdapter.Create;
  FEasyTrainerController := TEasyTrainerController.Create(FCEBackendAdapter);

  FCEProcessProbe := TCEProcessProbe.Create;
  FAutoReattachService := TAutoReattachService.Create('', FCEProcessProbe);
  FAutoReattachService.MinReattachIntervalTicks := 10;

  FAutoReattachService.OnLog := procedure(const Msg: String)
  begin
    // 输出到 CE 状态栏或日志
    if Assigned(StatusBar1) then
      StatusBar1.SimpleText := '[EasyTrainer] ' + Msg;
  end;

  FAutoReattachService.OnReattach := procedure
  begin
    // 自动重新附加
    if not FEasyTrainerController.Attach(FLastProcessName) then
      StatusBar1.SimpleText := 'Auto-reattach failed: ' + FEasyTrainerController.LastError
    else
      StatusBar1.SimpleText := 'Auto-reattach successful';
  end;
end;
```

在 `FormDestroy` 中清理：

```pascal
procedure TMainForm.FormDestroy(Sender: TObject);
begin
  // 清理 Easy Trainer
  if Assigned(FAutoReattachService) then
  begin
    FAutoReattachService.Stop;
    FAutoReattachService.Free;
  end;

  if Assigned(FEasyTrainerController) then
    FEasyTrainerController.Free;

  // ... 现有清理代码 ...
end;
```

### 步骤 3：集成自动重连

在现有定时器（或新定时器）中调用 Tick：

```pascal
procedure TMainForm.Timer1Timer(Sender: TObject);
begin
  // ... 现有代码 ...

  // Easy Trainer 自动重连
  if Assigned(FAutoReattachService) then
    FAutoReattachService.Tick;
end;
```

在进程附加后启动重连服务：

```pascal
procedure TMainForm.ProcessOpened(processid: THandle; processhandle: DWORD; caption: string);
begin
  // ... 现有代码 ...

  // 保存进程名用于自动重连
  FLastProcessName := ExtractFileName(caption);

  // 启动自动重连
  if Assigned(FAutoReattachService) then
  begin
    FAutoReattachService.Stop;
    FAutoReattachService := TAutoReattachService.Create(FLastProcessName, FCEProcessProbe);
    FAutoReattachService.Start;
  end;
end;
```

### 步骤 4：集成智能持久化

在加载 CT 表后，为每条记录分析持久化策略：

```pascal
procedure TMainForm.LoadCTTable(const FileName: String);
var
  i: Integer;
  memrec: TMemoryRecord;
  smartEntry: PSmartEntry;
  entries: TList;
begin
  // ... 现有加载代码 ...

  // 分析持久化策略
  entries := TList.Create;
  try
    for i := 0 to addresslist1.Count - 1 do
    begin
      memrec := TMemoryRecord(addresslist1[i]);
      if memrec <> nil then
      begin
        smartEntry := CreateSmartEntry(
          memrec.Address,
          memrec.Value,
          Ord(memrec.VarType),
          memrec.Description
        );

        // 根据置信度标记颜色
        if smartEntry^.Persistence.Confidence >= 80 then
          memrec.Color := clGreen
        else if smartEntry^.Persistence.Confidence >= 50 then
          memrec.Color := clYellow
        else
          memrec.Color := clRed;

        entries.Add(smartEntry);
      end;
    end;

    // 保存智能表
    SaveSmartTable(ChangeFileExt(FileName, '.smart'), entries);
  finally
    entries.Free;
  end;
end;
```

### 步骤 5：集成 CT 扩展

在保存 CT 表时注入 Easy Trainer 元数据：

```pascal
procedure TMainForm.SaveCTTable(const FileName: String);
var
  xml: TStringList;
  xmlWithMeta: String;
  meta: TCEEasyMetadata;
begin
  // ... 现有保存代码 ...

  // 读取保存的 XML
  xml := TStringList.Create;
  try
    xml.LoadFromFile(FileName);

    // 注入元数据
    meta := DefaultMetadata;
    meta.Version := '1.0';
    meta.AutoReattach := FAutoReattachService.Enabled;
    meta.PreferredStrategy := 'hybrid';
    meta.Notes := 'Generated by CE Easy Trainer';

    xmlWithMeta := InjectOrUpdateMetadata(xml.Text, meta);
    xml.Text := xmlWithMeta;
    xml.SaveToFile(FileName);
  finally
    xml.Free;
  end;
end;
```

## 简化 UI 集成（可选）

如果需要创建简化的 UI 入口：

### 添加按钮到 MainForm

```pascal
procedure TMainForm.btnEasyTrainerClick(Sender: TObject);
var
  processName: String;
  ctFile: String;
begin
  // 简化流程示例
  if not InputQuery('Easy Trainer', 'Process name:', processName) then Exit;

  if not FEasyTrainerController.Attach(processName) then
  begin
    ShowMessage('Attach failed: ' + FEasyTrainerController.LastError);
    Exit;
  end;

  // 显示 CT 选择对话框
  if OpenDialog1.Execute then
    ctFile := OpenDialog1.FileName
  else
    Exit;

  if not FEasyTrainerController.LoadTable(ctFile) then
  begin
    ShowMessage('Load table failed: ' + FEasyTrainerController.LastError);
    Exit;
  end;

  if not FEasyTrainerController.ApplyPreset('default') then
  begin
    ShowMessage('Apply preset failed: ' + FEasyTrainerController.LastError);
    Exit;
  end;

  ShowMessage('Easy Trainer activated successfully!');
end;
```

## 注意事项

1. **平台限制**：
   - `CEBackendAdapter` 中的进程附加/导出功能仅在 Windows 可用
   - 核心单元（`SmartPersistenceUnit` 等）跨平台

2. **性能考虑**：
   - 自动重连使用 Tick 轮询，避免高频线程
   - 智能持久化分析可能耗时，建议后台执行

3. **兼容性**：
   - CT 扩展使用独立命名空间，不影响旧版 CE
   - 保持与现有 CT 表格式的完全兼容
